# Куда звонить

`pal-directory` · куда звонить в вашем регионе, если нужна паллиативная помощь: про обезболивание, лекарства и если отказали. У каждой записи видно, откуда она и когда её сверяли

*Where to call in your Russian region about palliative care: pain relief, medicines, complaints. Every entry shows its source and date. [English below](#english)*

**Сайт:** https://openpalliative.github.io/pal-directory/ · **Статус:** в работе · **Звонком номера пока никто не проверял**

> **Это не служба помощи.** Если человеку плохо прямо сейчас, звоните **112** или **103**. Горячая линия помощи неизлечимо больным людям **8-800-700-84-36**: это сторонняя линия, мы с ней не связаны, номер взят с сайта линии и пока не сверен

## Что это

Вы выбираете регион и видите карточку: куда звонить по обезболиванию и паллиативной помощи, если такая линия есть, куда по лекарствам (орган здравоохранения региона), куда, если отказали или не отвечают (Росздравнадзор и ТФОМС), и где посмотреть, кто в регионе оказывает паллиативную помощь. Карточку можно распечатать на один-два листа A4 и повесить у телефона

## Для кого

- **Семьи и ухаживающие:** быстро найти, куда звонить, не перебирая сайты ведомств
- **Хосписы и НКО:** распечатать карточку для подопечных или передать ссылку
- **Разработчики:** те же данные в JSON и CSV со схемами, регион по коду ISO 3166-2

## Что на сайте

| Страница | Что там |
|---|---|
| `/pal-directory/` | поиск региона (понимает «ё» и «е», «СПб», «Югра», столицы) и список всех регионов. Работает без JavaScript |
| `/pal-directory/regions/<код>/` | карточка региона, например `regions/ru-kgd/`: ведомства, номера или ссылка на таблицу, часы дословно из источника, статус проверки, печать |
| `/pal-directory/federal/` | номера по всей стране с источником |
| `/pal-directory/routes/<код>/` | кто оказывает паллиативную помощь в регионе по официальному приказу. Например, Калининградская область (приказ министерства здравоохранения области от 09.09.2026 № 678). Все маршруты списком: `/pal-directory/routes/` |
| `/pal-directory/data/` | откуда данные, дата файла, сколько регионов и записей, что не проверено, ссылки на JSON и CSV |

Если у региона есть официальные акты о паллиативной помощи на портале publication.pravo.gov.ru, на карточке появляется блок «Официальные документы региона»: тип, дата, номер, название и ссылка на публикацию. Только сведения о документе, без пересказа и толкования

Сайт может запомнить ваш регион в этом браузере, кнопка «забыть» его стирает. Ссылка «Нашли ошибку в номере?» открывает готовое сообщение на GitHub или даёт текст, который можно скопировать и передать через фонд

## Режимы данных

Сборку задаёт переменная `PD_DATA_MODE`:

| Режим | Что на карточке | Где используется |
|---|---|---|
| `real` | номера из таблицы Росздравнадзора с подписью и статусом «Не проверено» | локально по умолчанию |
| `links` | названия ведомств и адреса территориальных органов Росздравнадзора без номеров регионов, ссылка на таблицу Росздравнадзора и дата файла | GitHub Pages и релизы, пока переменная репо `PD_DATA_MODE` не задана |
| `demo` | выдуманные номера вида `8 (000) ...` без ссылок для звонка и плашка «Пример на выдуманных данных» | только локально и в тестах |

Какой режим сейчас на сайте, видно на странице «Откуда данные». Федеральные номера, названия ведомств и маршруты публикуются во всех режимах

## Откуда данные

| Что | Источник | Как сверено |
|---|---|---|
| Номера, подписи и часы по регионам | таблица Росздравнадзора «Номера телефонов «Горячих линий» в субъектах Российской Федерации», [страница](https://roszdravnadzor.gov.ru/pages/main/call/to/tel) | разобрана скриптом, sha256 файла в `data/snapshots/rzn-hotlines.json`. Строки с ошибкой в номере на сайт не идут, пробел в источнике показан на карточке |
| Горячая линия Росздравнадзора | подвал той же страницы | дословно |
| Названия и адреса территориальных органов Росздравнадзора | открытые данные Росздравнадзора, набор [7710537160-lta](https://roszdravnadzor.gov.ru/opendata/7710537160-lta) | дословно, ФИО руководителей отброшены до записи |
| Перечни медицинских организаций по региональным приказам | [publication.pravo.gov.ru](http://publication.pravo.gov.ru/), номер публикации у каждой записи | OCR скана, строки сверяются со страницами. Пока страница не подписана проверяющим, строка `verified: false` |
| Индекс региональных актов о паллиативной помощи | API publication.pravo.gov.ru | только метаданные: номер, дата, название, орган, ссылка |
| Москва, Московская область, Санкт-Петербург, Ленинградская область | ссылки на официальные списки организаций | только ссылки, `verified: false` |

Данные в JSON и CSV: `https://openpalliative.github.io/pal-directory/data/v1/index.json`. Каждый набор со схемой, датой и лицензией

### Как обновляется

- **Наблюдатель** (`.github/workflows/watch.yml`, `pipeline.watch`) сверяет файл на сайте Росздравнадзора со снимком. Если файл тот же, коммитит новую дату проверки и пересобирает сайт. Если файл новый, открывает pull request с таблицей «было / стало» и меткой `review:data`, и его смотрит человек: номера на сайте сами не меняются. Если файл не открывается три недели подряд, формат сломался или файлу больше года, открывается issue с меткой `watch:*`
- **По расписанию наблюдатель запускается, только если мейнтейнер включил переменную `WATCH_ENABLED`.** По умолчанию расписание выключено, работает ручной запуск
- **Открытые данные Росздравнадзора и индекс актов** обновляет мейнтейнер вручную, тем же пайплайном
- **Проверка звонком** делает только куратор региона в России, см. [docs/CURATORS.md](docs/CURATORS.md)

## Источники и санкционные рамки

Пайплайн и GitHub Actions ходят в сеть только по этому списку, и только читают:

| Адрес | Кто ходит | Что берёт |
|---|---|---|
| `https://roszdravnadzor.gov.ru/pages/main/call/to/tel` | наблюдатель | ссылку на файл таблицы и номер горячей линии из подвала |
| файл `.xlsx` по ссылке с этой страницы на `roszdravnadzor.gov.ru` | наблюдатель | таблицу горячих линий |
| `https://roszdravnadzor.gov.ru/opendata/7710537160-lta/meta.csv` и файл набора по ссылке из него | `pipeline.fetch_lta`, вручную | названия и адреса территориальных органов |
| `http://publication.pravo.gov.ru/api/PublicBlocks`, `/api/Documents`, `/api/Document` | `pipeline.pravo_acts`, вручную | метаданные официальных публикаций |
| `http://publication.pravo.gov.ru/file/pdf?eoNumber=...` | пайплайн данных, вручную | скан приказа для разбора маршрута |

Кроме этого Actions обращаются только к служебным адресам: GitHub, PyPI, npm, загрузка браузеров Playwright

- Сайты НКО, медицинских организаций и других ведомств пайплайн не открывает, номера сетью не проверяет
- Список хостов закреплён в коде (`pipeline/net.py`), тест падает на любом другом адресе
- Публикуются только 83 субъекта из `data/regions.csv`. Строки других территорий из таблиц источников отбрасываются в коде до записи (`pipeline/territories.py`), региональные блоки портала pravo.gov.ru по ним не запрашиваются
- Сервера у проекта нет, сайт в браузере читает только свои файлы

Подробнее в [ARCHITECTURE.md](ARCHITECTURE.md), раздел 3.10

## Что пока не проверено

- **Ни один номер не проверен звонком.** У всех стоит «Не проверено». Это поменяет только куратор региона, а кураторов пока нет
- **Перечни организаций по приказам и цитата горячей линии Росздравнадзора** ещё не подписаны вторым проверяющим, поэтому `verified: false`
- **Тексты не проверял юрист в России.** Страницы маршрутов помечены как черновик
- **Тип регионального акта** (маршрут, организация помощи, возмещение) определяется словарём по названию и помечен как непроверенный
- **Тему номера** (обезболивание, лекарства, жалобы) определяет словарь по подписи. Подпись из таблицы всегда видна рядом
- ОКТМО в таблице нет, поле пустое

Нашли ошибку: [issue по форме «Неверный номер»](https://github.com/openpalliative/pal-directory/issues/new?template=wrong-number.yml). Номер посмотрит мейнтейнер, проверку звонком делает куратор региона, если он есть. Сообщение увидят все, не пишите ФИО, диагнозы и адреса

## Как запустить у себя

Нужны Python 3.12 через [uv](https://docs.astral.sh/uv/) и Node 22+ через pnpm. Сеть нужна только для установки

```sh
uv sync && pnpm install
uv run python -m opsite build
sh scripts/serve-one --port 8705 --no-open
```

Откройте http://localhost:8705/pal-directory/. Другой режим: `PD_DATA_MODE=links uv run python -m opsite build`. Ссылки в соседние разделы (заявления, листы для дома, нормы) работают, когда собраны все сайты и запущен общий `../serve.sh` на http://localhost:8080/

- сверить таблицу на сайте Росздравнадзора со снимком: `uv run python -m pipeline.watch` (ходит только на roszdravnadzor.gov.ru)
- разобрать скачанный xlsx вручную: `uv run python -m pipeline.parse_rzn путь/к/файлу.xlsx`
- обновить названия и адреса территориальных органов из открытых данных: `uv run python -m pipeline.fetch_lta`
- обновить индекс региональных актов: `uv run python -m pipeline.pravo_acts` (запросы идут по одному с паузой, это занимает время)
- проверка перед коммитом: `sh scripts/gate.sh` (pytest, сборка, проверка текста, ссылок и бюджетов, юнит-тесты, e2e с axe в обеих темах, печать, скриншоты)
- общий интерфейс берётся из хаба скриптом `scripts/sync-ui`, руками в `opsite/` не правят

## English

pal-directory is a static site with regional hotlines and agencies in Russia for palliative care questions: pain relief, medicines and complaints. Data comes from the Roszdravnadzor hotline table, Roszdravnadzor open data and official publications on publication.pravo.gov.ru. Every entry has a source and a date, and nothing is marked as verified until a regional curator in Russia has called the number. No numbers have been checked by phone yet

- Site: https://openpalliative.github.io/pal-directory/, data: `/pal-directory/data/v1/index.json`
- Data modes: `real` (numbers from the table), `links` (agencies and addresses, no regional numbers; the default on Pages until the `PD_DATA_MODE` repository variable is set), `demo` (synthetic, local only)
- Network access is limited to the addresses listed above. Only the 83 regions in `data/regions.csv` are published, rows for other territories are filtered out in code
- Run locally: `uv sync && pnpm install && uv run python -m opsite build && sh scripts/serve-one --port 8705`
- Code is MIT, data follows `LICENSE-DATA`. Not affiliated with any government body, fund or medical organisation

## Дисклеймер

Это справочник, а не медицинская или юридическая консультация. Номера взяты из открытой таблицы Росздравнадзора и могут устареть: перед важным звонком сверьтесь с сайтом ведомства. Проект не связан с Росздравнадзором, органами здравоохранения, фондами ОМС, медицинскими организациями и НКО, не принимает обращения и не собирает деньги
