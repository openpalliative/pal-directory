# pal-directory: архитектура

Срез 11.10.2026. Инструмент «Куда звонить» (идея 10 проекта, `region-lines`). Работает поверх стандарта `../PLATFORM.md` и карты `../UX_MAP.md`. Если что-то здесь им противоречит, правы они, а расхождение пишем в `../STATUS.md`.

Префикс `pd`, порт 8705, адрес на Pages `/pal-directory/`, PWA нет, `draft_default: none` (маршрут по приказу помечается черновиком отдельно).

## 0. Главные решения

| # | Решение | Почему |
|---|---|---|
| A1 | Регион = ISO 3166-2:RU (`RU-KGD`), адрес карточки `/regions/ru-kgd/` | PLATFORM 2.2 и UX_MAP 11.7. **ОКТМО в xlsx РЗН нет** (регион записан только названием), поэтому взять ОКТМО из источника нельзя. Поле `oktmo` есть, пока `null`, заполнит мейнтейнер в РФ |
| A2 | `verified` у номера значит только «подтверждено звонком куратора в РФ». В MVP у всех номеров `false` | Мейнтейнеры вне РФ звонить не могут, звонит только куратор в РФ (`docs/CURATORS.md`). Номер из таблицы РЗН показываем со статусом «Не проверено» и подписью «так в таблице Росздравнадзора от 03.03.2026» (UX_MAP 11.11) |
| A3 | Роль номера угадывается словарём по подписи, но рядом всегда видна дословная подпись источника. Флаг `topics_checked` ставит человек | В xlsx нет поля роли, есть только свободный текст |
| A4 | «Круглосуточно» только если слово «круглосуточ» стоит в том же фрагменте и не ограничено («круглосуточно в выходные» не считается). «24» не считается | Ложное 24/7 ночью опаснее отсутствия номера |
| A5 | Сырой xlsx в git **не коммитим**. В репо только url, sha256, ETag, Last-Modified и счётчики (`data/snapshots/`), разобранный и вычищенный `data/rzn/lines.csv` и сведения об источнике в `raw/SOURCES.tsv`. Сам файл живёт в `raw/cache/` (в `.gitignore`) | В ячейках Ростова ФИО, у иркутского ТФОМС e-mail, плюс строки 6 территорий. Из истории git это не вычистить |
| A6 | Публикуются только 83 субъекта из `data/regions.csv`. Строки других территорий из таблицы РЗН и открытых данных отбрасываются в коде до записи (`pipeline/territories.py`, шаблоны в `opsite/lint/territories.yaml`), остаётся только их число в `counts.excluded`. Названия этих территорий есть только в фильтре и его тесте | PLATFORM 4.1, постоянное правило проекта |
| A7 | Федеральные 112, 103 и 8-800-700-84-36 не дублируем: берём из `opsite/now.yaml` хаба (`opdata.now`). Свой `data/federal.yaml` только для номеров, которых там нет: горячая линия Росздравнадзора +7 800 550 99 03 (дословно из подвала страницы РЗН). **122 федеральным номером не считаем**: источника нет, 122 показываем только там, где он стоит в строке региона | Критика п. 6 и 8 |
| A8 | Режим данных `PD_DATA_MODE`: `real` (локально по умолчанию, номера из таблицы РЗН), `links` (на Pages и в релизе по умолчанию: `region-lines` без номеров, на карточке названия ведомств, адреса ТО и ссылка на таблицу РЗН с датой файла) или `demo` (только локально и в тестах: синтетика `8 (000) ...` без `tel:`, `origin: synthetic`). На Pages и в релизе режим задаёт `vars.PD_DATA_MODE`, пустая переменная значит `links`. `regions`, `addressees`, `routes`, `routers`, `federal-lines` публикуются всегда | Синтетика в проде вредна, а реальные номера публикуются только решением мейнтейнера через переменную репо. Названия ведомств - низкий риск, они нужны `obrashchenie-kit` |
| A9 | Маршрут Калининграда 678: перечень МО (таблицы 1 и 2 приложения 2 к приказу) и дословные пункты правил. **Районы к МО не привязываем**: в приказе привязки нет, догадка по названию ЦРБ не годится. Анкету, критерии с баллами и прогнозом в месяцах не берём (ПП 1684) | Обе позиции и критика п. 6, 7 |
| A10 | Маршрутизаторы Москвы, МО, СПб и ЛО - только ссылки и номера из исследований с `verified:false`. «ЕКЦ Москвы» не пишем: ни URL, ни источника нет | Ничего не выдумывать |
| A11 | Пайплайн ходит в сеть только по точному списку адресов из 3.10: страница и файл горячих линий и открытые данные `roszdravnadzor.gov.ru`, API и PDF `publication.pravo.gov.ru`. Allowlist хостов и путей в коде и тест на него | Санкционные рамки проекта, раздел 3.10 |
| A12 | «Сообщить об ошибке» - ссылка на issue form GitHub с предзаполнением из query, плюс кнопка «Скопировать текст ошибки» для передачи через НКО. Предупреждение: issue публичный, нужен аккаунт GitHub, ФИО и диагноз не писать | Без сервера и без личной почты мейнтейнеров |

## 1. MVP и что позже

### MVP (этот прогон)

- **Данные**
  - 83 региона из xlsx РЗН от 03.03.2026: все строки ТО РЗН, органа здравоохранения и ТФОМС, разобранные на номера с подписью, часами, флагами и ролью
  - 6 территорий исключены с пометкой
  - `addressees`: названия ведомств по региону без адресов
  - федеральный блок
  - 4 карточки маршрутизаторов (Москва, МО, СПб, ЛО)
  - маршрут Калининграда 678 (`verified:false`, черновик)
  - 7 публикуемых датасетов, синтетика для `demo`
- **Сайт:** главная с поиском и алфавитным списком (работает без JS), 83 карточки региона, `/federal/`, `/routes/ru-kgd/`, `/data/`, печать карточки на A4, «сообщить об ошибке», запоминание региона с «забыть»
- **Автоматика:** `watch.yml` (еженедельно, снимок, PR при изменении, issue при поломке формата или недоступности), `checks.yml`, `pages.yml`, issue form `wrong-number.yml`
- **Тесты:** pytest на реальном xlsx (локально) и на синтетических xlsx (CI), node --test, Playwright с axe, сетью, печатью, без JS

### Позже (не в этом прогоне)

- СПб 87-р (`/routes/ru-spe/`, OCR уже лежит) только для сверки с AdVita
- районные маршруты ещё примерно 9 регионов (около 26 актов) при живом кураторе. Поиск новых актов делает наблюдатель `pal-norms`, здесь не дублируем
- кураторы: строки `origin: curator`, `verified:true` после звонка, правило 180 дней, стоп-критерий «6 мес. без куратора» (только для регионов, где куратор уже был)
- ОКТМО, выбор района
- флаг межрегионального возмещения из `pal-norms`
- автоматическая «заморозка», если 6 мес. нет мейнтейнера в РФ (сейчас только поле в `meta.yaml` и проверка в watch, см. 5)
- перенос `<pd-region-search>` и `xparams` в платформу как `<op-region>` и `xparams.js`

### Убрано из обеих позиций

Раскладка «rfkby», резервный парсер HTML-таблицы (пропала ссылка - это issue, а не второй парсер), ежемесячный поиск актов в pravo (это `pal-norms`), свёрнутые «прочие номера» на карточке (вакцинация, оплата труда, ковид: только в JSON), привязка районов Калининграда к МО, 122 как федеральный номер, «ЕКЦ Москвы», латинские слаги-транслит (UX_MAP выбрал ISO).

## 2. Страницы и маршруты

Шапка, подвал, крошки, `op-now`, `op-data-date`, статусы, черновик - из `opsite` (PLATFORM 3). `site.nav`: «Регионы» (`""`), «По всей стране» (`federal/`). В подвале инструмента ссылка «Откуда данные» на `data/`.

Все номера: `tel:`, цифры в одну строку (`white-space: nowrap`), подпись переносится. У каждого номера: назначение дословно, часы дословно, «Круглосуточно» только по A4, тип номера («мобильный», «бесплатный»), «Этот же номер указан у: Хабаровский край» при `shared_with`, статус «Не проверено». Размер: `verified:true` 24-28px (в MVP таких нет), `verified:false` 20px Onest 600, подчёркнут.

### 2.1 `/` - «Куда звонить»

1. H1 «Куда звонить», строка «У каждого номера указаны его назначение, источник и дата проверки»
2. `op.now(compact=true)`: «Угроза жизни: 112 или 103» двумя кнопками 48px, ниже 8-800-700-84-36 обычной ссылкой со статусом «Не проверено» и «сторонняя линия» (UX_MAP 11.13)
3. Если в `localStorage['op.region']` есть регион: «Ваш регион: Калининградская область · открыть · забыть»
4. Поле «Ваш регион» (`<pd-region-search>`): подсказка «Например: Иркутская, СПб, Югра, Казань». Фильтрует уже отрисованный список, без запросов. Понимает ё/е, регистр, дефисы, алиасы и столицы (раздел 3.2). Enter при одном совпадении открывает карточку
5. Буквы-якоря (А Б В ...) кнопками-ссылками от 44x44px
6. Полный алфавитный список 83 регионов ссылками на `regions/<slug>/`. Без JS это и есть выбор
7. Последний пункт «Моего региона нет в списке» ведёт на `federal/` («Звоните на номера, которые работают по всей стране»). Исключённых территорий нет ни в списке, ни в HTML
8. `op-data-date`: «Данные от ...» (дата последней успешной проверки watch)

**Первый экран 360x640:** шапка в две строки, H1 и строка, компактный `op-now`, «Ваш регион» (если есть), поле поиска. Список регионов ниже сгиба.

### 2.2 `/regions/<slug>/` - карточка региона (83 страницы)

`slug` = ISO в нижнем регистре (`ru-kgd`), ISO в `data-region`. Крошки «openpalliative › Куда звонить › Калининградская область».

1. H1 = название региона, под ним «Куда звонить в регионе». Строка `<pd-remember>`: «Запомнили как ваш регион · забыть» (регион пишется в `op.region` при открытии карточки, UX_MAP 5.4 и 11.4)
2. `op.now(compact=true)`: «Угроза жизни: 112 или 103». Никаких «сначала звоните сюда» и признаков состояния (ПП 1684)
3. **«Обезболивание и паллиативная помощь»**: строки с темой `pain` или `pmp`. Если таких нет: «В таблице Росздравнадзора для этого региона нет отдельной линии по обезболиванию или паллиативной помощи» и ссылка на `federal/`
4. **«Медицинская помощь и лекарства»**: строки органа здравоохранения с темами `general`, `drugs`
5. **«Если отказали или не отвечают»**: ТО Росздравнадзора и ТФОМС (строки с темами `general`, `complaints`), горячая линия Росздравнадзора из `federal-lines`. Ссылки «Написать жалобу» (`xurl('obrashchenie-kit', 'case/', {new:1, region:'RU-KGD'})`) и «Если не ответили: что дальше» (pn `escalation/`)
6. **«Кто оказывает паллиативную помощь в регионе»**:
   - есть маршрут: карточка-ссылка на `routes/ru-kgd/` с отметками «Черновик» и «Демо»
   - есть маршрутизатор: название, оператор («государственный» или «некоммерческая организация»), внешняя ссылка с иконкой `external-link` и «откроется сайт palliative.advita.ru», номер со статусом «Не проверено», строка «Проект с этой организацией не связан»
   - иначе: «Перечня медицинских организаций по этому региону пока нет»
7. «Вписать номера в карту на ночь» -> hc `night/#region=RU-KGD`
8. Нижний блок: «Таблица Росздравнадзора от 03.03.2026. На сайте Росздравнадзора без изменений на 11.10.2026» (из снапшота), ссылка на страницу источника, `op-data-date`, `<op-print>`, `<pd-report>`
9. Статус `stale` на карточке, если файлу РЗН больше 12 месяцев (`assured_date`)

Строки с темами `other` и `staff` (вакцинация, ковид, оплата труда, приёмная директора) на карточке не показываем, они есть в JSON. Каждая строка видна один раз, в первом подходящем блоке по порядку 3, 4, 5.

**Первый экран 360x640:** крошки, H1, строка «запомнили · забыть», компактные 112/103, заголовок блока 3 и первый номер.

**Печать (A4, та же страница, `assets/css/pd-print.css` поверх `print.css`):** заголовок региона, блоки 3-5 и 6 текстом (URL внешних ссылок печатаются), каждая строка со статусом «Не проверено», `.op-sheet-footer` «Таблица Росздравнадзора от 03.03.2026, звонком не проверено. Сверьте до <дата печати + 90 дней>» и адрес страницы. `<details>`, кнопки, `pd-remember`, `pd-report` не печатаются. Цель: 1 лист у Калининграда и Иркутской области (самая длинная), не больше 2 у любого региона. Карточка pd - справочная распечатка, а не лист для дома: правило fail closed для листов `home-care-kit` здесь не действует, но статус «Не проверено» печатается у каждого номера.

### 2.3 `/federal/` - «Номера по всей стране»

Из `opdata.now`: 112, 103 (с цитатой приказа Минцифры 75 и eoNumber), 8-800-700-84-36 (сторонняя, «Не проверено»). Из `federal-lines`: горячая линия Росздравнадзора «по соблюдению прав граждан в сфере охраны здоровья» +7 800 550 99 03, источник - страница roszdravnadzor.gov.ru, дата чтения. Строка «Номер 122 работает не во всех регионах, он указан в карточках тех регионов, где стоит в таблице Росздравнадзора». Печать на 1 лист.

### 2.4 `/routes/ru-kgd/` - «Калининградская область: кто оказывает паллиативную помощь взрослым»

- `op.draft('legal')` и статус «Не проверено»: «Перечень распознан со скана официальной публикации и ещё не сверен по скану вручную»
- акт: название, номер, дата, `op-cite` с eoNumber `3901202609100002` и ссылкой `http://publication.pravo.gov.ru/document/3901202609100002`
- дословные пункты правил (`op-quote`): п. 1 (право на выбор врача и МО), п. 2 (решение врачебной комиссии в той МО, где человек получает помощь), без отсылок к анкете и критериям
- таблица «В амбулаторных условиях» (18 строк): организация, подразделение дословно
- таблица «В стационарных условиях»: организация, подразделение
- строка «Анкета и критерии из приложений к правилам здесь не приводятся. Их применяет врачебная комиссия»
- **районов нет**

### 2.5 `/data/` - «Откуда данные»

- Источник: страница и файл РЗН (точные URL), дата файла, sha256, дата последней проверки
- Как разбираем: номер, подпись, часы, «круглосуточно» только по слову
- Что не делаем: «Мы никуда не звоним и не проверяем сайты организаций. Номера подтверждают кураторы в регионах, их пока нет»
- Охват: сколько регионов, у скольких есть линия по обезболиванию или паллиативной помощи (число считает сборка)
- `counts.excluded` с пояснением «решение за мейнтейнером в РФ» (UX_MAP 11.14)
- Лицензия: «на условиях источника Росздравнадзора, с указанием источника», разметка CC0
- Датасеты: ссылки на `data/v1/*.json` и схемы, пример строки
- Как помочь: «Сообщить об ошибке», «Стать куратором региона» (ссылка на README)

### 2.6 Отчёт об ошибке

`<pd-report>` строит ссылку только через `lib/issue-url.js`:

```
https://github.com/openpalliative/pal-directory/issues/new?template=wrong-number.yml&title=<enc "Номер: Калининградская область, 8 (4012) 53-52-02">&region=RU-KGD&line=ru-kgd-rzn-84012535202&data_version=2026.10.11
```

Рядом текст «Откроется GitHub. Нужен аккаунт. Сообщение будет видно всем: не пишите ФИО, диагнозы и адреса». Кнопка `<op-copy>` «Скопировать текст ошибки» копирует то же самое обычным текстом. Без JS ссылка уже собрана сборкой в HTML.

### 2.7 Свои компоненты (light DOM, `assets/js/`)

| Файл | Элемент | Что делает |
|---|---|---|
| `region-search.js` | `<pd-region-search>` | фильтрует `ul[data-pd-regions] > li[data-search]`, `aria-live` «Найдено: 3», пусто: «Не нашли. Проверьте название или выберите по букве» |
| `remember.js` | `<pd-remember>` | `op.region` читать, писать, «забыть». Всё в try/catch |
| `report.js` | `<pd-report>` | только `op-copy` поверх готовой ссылки |
| `params.js` | | локальный `readParams(['region','back'])` до появления `opsite/ui/js/xparams.js`. На `/` с `#region=RU-KGD` переход на карточку |

Чистые функции без DOM в `lib/normalize.js` (`normalize`, `matchRegion`) и `lib/issue-url.js` (`issueUrl`, `issueText`), публикуются в `/pal-directory/lib/`. Разметку номера рисует макрос `templates/partials/pd.html.j2: line(item, regions)`, одна на сайт.

### 3.11 `data/rzn/lta.csv`, `data/snapshots/rzn-lta.json` (генерирует `pipeline.fetch_lta`)

E-mail сохраняется, только если он на домене `*.roszdravnadzor.gov.ru`, иначе пусто и счётчик `emails_dropped`. ТО сопоставляется с регионами по `name_dative` из названия «Территориальный орган Росздравнадзора по ...»; несопоставленная строка останавливает разбор.

Поля: `source_row`, `region_ids` (`;`), `name`, `full_name`, `postal_address`, `email`, `hours_text` (дословно `work_mode`). На 01.10.2026: 73 ТО покрывают 81 регион, без ТО Москва и Московская область. Название ТО в `addressees` берётся отсюда, старое название из таблицы горячих линий уходит в `name_hotlines` (Липецкая, Владимирская, Ивановская, Воронежская области, Чукотка, ЕАО, Хабаровский край, Кузбасс). В улицах вроде «пл. В.И. Ленина» регулярка ФИО срабатывает, тест такие совпадения после «ул.», «пл.», «пр.» не считает.

### 3.12 `data/pravo/region-acts.csv` (генерирует `pipeline.pravo_acts`)

Индекс официальных региональных актов о паллиативной помощи, только метаданные. Для каждого из 83 блоков (`regions.csv:pravo_block`) последовательно, с паузой 2 с, запросы `/api/Documents?Block=<блок>&Name=<слово>` по словоформам «паллиативной», «паллиативную», «паллиативная», «паллиативных», «хоспис» (поиск портала идёт по точной словоформе в названии). Дедуп по eoNumber, `eoNumber[:2]` сверяется с номером блока, несовпадения отбрасываются и считаются. Блоки территорий из фильтра в denylist и не запрашиваются. Тексты и PDF не скачиваются.

Поля: `id` (= eoNumber), `region_id`, `act_type`, `authority` (из `complexName` до « от »), `number`, `doc_date`, `publish_date`, `title` (дословно поле `name`), `pages`, `url`, `kind` (словарь по названию: `routing`, `organization`, `program`, `reimbursement`, `nutrition`, `devices`, `subsidy`, `other`), `words`, `retrieved_at`. В JSON добавляются `kind_checked` (из `data/review/acts.csv`: `id,kind,kind_checked,checked_by,checked_at,note`), `verified: true` (метаданные взяты с портала), `source_ref: pravo-api`. На 12.10.2026: 306 актов в 70 регионах. `python -m pipeline.pravo_acts --reclassify` пересчитывает `kind` без сети. Ответы API для тестов в `pipeline/tests/fixtures/pravo/` (блоки и два региона), полный кэш ответов в `raw/cache/pravo/`, хеши в `raw/pravo-acts/MANIFEST.sha256`.

### 3.13 Пробелы источника: `data/rzn/gaps.csv`, `rzn_missing`

Парсер пишет в `gaps.csv` строки таблицы РЗН, где номер набрать нельзя: `malformed` (номер записан с ошибкой, дословный фрагмент) и `no_number` (в ячейке нет ни одного номера, дословный текст ячейки). Сейчас это Чечня и Липецк (`malformed`, минздрав) и ЕАО (`no_number`, департамент). В `regions` это `source_gaps`. Если у региона нет строки ТО ни в таблице, ни в открытых данных, у него `rzn_missing: true` и `rzn_missing_reason` с датами обоих источников (Москва, Московская область). Адресат без официального источника не заводится. Тест падает, если у региона нет ТО и нет флага.

### 3.14 Подпись страниц скана: `data/review/scan_pages.yaml`

Строка маршрута (`units`) и цитата (`quotes`) получают `scan_checked_at`, если в `scan_pages.yaml` есть подпись этой страницы этого eoNumber с ключом строки (`ambulatory 16`) или пунктом цитаты. `verified: true` только при второй подписи (`second_check`) другим человеком. Маршрут целиком `verified`, только когда подписаны все строки и цитаты. Считает `pipeline/routes_review.py`, руками в yaml маршрута не ставится.

**`pipeline.watch` по шагам:**

1. GET страницы, `href` на xlsx, GET файла (allowlist, таймаут 30 с, `User-Agent: openpalliative-watch (+https://github.com/openpalliative)`)
2. Недоступно: `unreachable_weeks += 1`, снимок коммитится как в п. 3. На 3-й неделе issue «Источник недоступен, нужен раннер в РФ» (`watch:unreachable`)
3. sha256 тот же: в снапшоте `checked_at`, в `meta.yaml` `data_date`. `watch.yml` прогоняет pytest, сборку и `opsite check`, потом коммитит факты `data: снимок Росздравнадзора <дата>` прямо в main. Коммит от `GITHUB_TOKEN` сам Pages не пересобирает, поэтому следующим шагом `watch.yml` запускает `gh workflow run pages.yml`. Расписание живым держит не коммит, а последний шаг `keepalive`. Если main защищён без обхода для Actions, этот коммит не пройдёт (см. `docs/release.md`)
4. sha256 новый:
   - парсер с инвариантами: лист `ПЕРЕЧЕНЬ`, заголовок с «Контактные номера», регионов 80-95, номеров не меньше 300, каждое `name_source` найдено в `regions.csv`
   - инвариант нарушен: issue «Формат таблицы Росздравнадзора изменился» (`watch:format`), данные не трогаем
   - иначе: новый `data/rzn/lines.csv` и снапшот уходят **PR** `watch/<дата>` (метка `review:data`, `peter-evans/create-pull-request`). В теле таблица по регионам «было / стало / пропал / новый номер» и список осиротевших правок из `overrides.csv`. `data_date` не двигается, пока PR не слит. Pytest в этом случае до PR не запускается: `watch.yml` после создания PR запускает `checks.yml` на его ветке (`gh workflow run checks.yml --ref <ветка>`), и падение видно в самом PR

6. `maintainer_ru_checked_at` задан и старше 180 дней: issue «Нет мейнтейнера в РФ 6 месяцев: заморозить данные» (`watch:freeze`)
