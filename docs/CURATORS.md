# Кураторы регионов

Номера на сайте взяты из таблицы Росздравнадзора. Таблица официальная, но номера в ней устаревают: линию переносят, часы меняются, трубку берёт другая служба. Узнать это можно только одним способом: позвонить. Это и делает куратор

## Кто такой куратор

Человек, который живёт в России и раз в полгода звонит по номерам своего региона. Можно быть куратором одного региона или нескольких. Это добровольно и без оплаты, никаких обязательств: можно остановиться в любой момент, достаточно написать об этом в своём issue

Куратор не консультирует семьи, не принимает обращения и не отвечает за работу ведомств. Он проверяет одно: отвечает ли номер и та ли это служба, что написана в подписи

Сейчас кураторов нет ни в одном регионе. Поэтому у всех номеров на сайте стоит «Не проверено»

## Как стать куратором

1. Прочитайте этот документ до конца
2. Откройте issue по форме [«Стать куратором региона»](https://github.com/openpalliative/pal-directory/issues/new?template=curator.yml). Нужен только аккаунт GitHub, можно под псевдонимом
3. Мейнтейнер ответит в том же issue и отметит регион как занятый

Мы не просим и не храним ваши ФИО, телефон, почту, адрес и место работы. Связь только через issue и pull request на GitHub. Списка кураторов с контактами нет и не будет

## Что делает куратор

**Раз в 180 дней** обзвонить номера своего региона, которые показаны на карточке. Проверка считается свежей 180 дней с даты звонка. Потом номер снова показывается как «Не проверено», пока его не проверят ещё раз

Для каждого номера отметить один результат:

| Результат | Что значит |
|---|---|
| отвечает | дозвонились, ответила служба из подписи, по теме из подписи |
| другая служба | номер работает, но отвечает не та организация или не по той теме |
| не отвечает | не дозвонились в часы работы из подписи за две попытки в разные дни |
| другие часы | служба та, но часы работы другие. Новые часы записать дословно, как сказали |

Если номер не работает или отвечает не та служба, правильный номер берите только из официального источника: таблица Росздравнадзора, открытые данные Росздравнадзора, официальная публикация на publication.pravo.gov.ru. Номер, который продиктовали по телефону, в данные не попадает, его можно только упомянуть в pull request, чтобы мейнтейнер нашёл официальный источник

## Как отмечать: pull request

Результат отмечается pull request в этот репо. У проверенной строки в данных появляются:

- `verified: true`, только при результате «отвечает»
- `verified_at`: дата звонка в виде `2026-10-12`
- `origin: curator` у строки, которую куратор добавил по официальному источнику, которого не было в таблице Росздравнадзора. У строки из таблицы остаётся `origin: rzn`

В pull request напишите регион, дату звонков и результат по каждому номеру. Мейнтейнер проверит, что файл собирается и в нём нет лишнего, и сольёт

**Что пока не сделано.** Файла для отметок звонков в `data/review/` и его разбора в сборке ещё нет, правило 180 дней тоже пока не проверяется автоматически. Это появится вместе с первым куратором. До этого результат можно прислать таблицей прямо в тексте pull request или issue, мейнтейнер перенесёт его в данные

## Чего куратор не делает и не пишет

- не пишет ФИО сотрудников, которые ответили, и их личные номера, даже если их назвали
- не пересказывает разговор и не пишет, по какому поводу звонил на самом деле, если звонил по своему делу
- не пишет ничего о больных, семьях и подопечных
- не записывает разговоры
- не звонит от имени проекта и не представляется сотрудником: достаточно спросить, туда ли вы попали и в какие часы работает линия
- не проверяет номера территорий, которых нет в списке регионов сайта: проект их не публикует

## Если куратора долго нет

Если в регионе был куратор, а новых отметок нет больше 180 дней, номера возвращаются в «Не проверено» (когда появится файл отметок, см. выше). Если в проекте 6 месяцев нет ни одного мейнтейнера в России, наблюдатель открывает issue с предложением заморозить данные. Решение принимают мейнтейнеры
